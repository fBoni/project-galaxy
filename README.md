## 🇺🇸 English

### About

**Project Galaxy** is a space shooter game developed with Godot Engine 4.7 as part of my studies in game development. It's a tribute to classic arcade games from the 80s, like *Asteroids* (1979).

### Mechanics

- Rotate the ship with **A** and **D**
- Accelerate with **W** (with thrust animation)
- Shoot with the **Spacebar**
- The ship features inertia — it slides after releasing the throttle

### Technologies

- **Engine**: Godot 4.7
- **Language**: GDScript
- **Art**: Pixel art (Piskel)
- **Resolution**: 640x480

### How to Run

1. Clone the repository
2. Open the project in Godot 4.7
3. Run the main scene (`level_1.tscn`)

## 🇧🇷 Português

### Sobre

**Project Galaxy** é um jogo de tiro espacial desenvolvido com Godot Engine 4.7 como parte dos meus estudos em desenvolvimento de jogos. É uma homenagem aos clássicos arcade dos anos 80, como *Asteroids* (1979).

### Mecânicas

- Rotacione a nave com **A** e **D**
- Acelere com **W** (com animação de propulsão)
- Atire com a **Barra de Espaço**
- A nave possui inércia — ela desliza após soltar a aceleração

### Tecnologias

- **Engine**: Godot 4.7
- **Linguagem**: GDScript
- **Arte**: Pixel art (Piskel)
- **Resolução**: 640x480

### Como Executar

1. Clone o repositório
2. Abra o projeto no Godot 4.7
3. Execute a cena principal (`level_1.tscn`)
